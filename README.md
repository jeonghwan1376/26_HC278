## 💡 1. 프로젝트 개요

### 1-1. 프로젝트 소개

- **프로젝트명:** Virtual to Real : 디지털 트윈 기반 물류 적재 공정의 AI동작 최적화 및 검증
- **프로젝트 번호:** 26_HC278
- **프로젝트 정의:** AI 비전으로 컨베이어 위 제품의 정상·불량 여부를 판별하고, 정상 제품의 3차원 위치와 회전각을 산출하여 3축 직교 로봇으로 자동 적재하는 물류 공정 시스템입니다. 포토센서 및 이송 정보를 활용하여 움직이는 트레이의 위치를 추적하고, 실제 설비 데이터를 NVIDIA Isaac Sim 디지털 트윈 및 통합 UI와 연동합니다.

### 1-2. 개발 배경 및 필요성

인건비 상승과 생산·물류 효율화 수요의 증가에 따라 제품 검사, 이송, 분류 및 포장 공정의 자동화 필요성이 확대되고 있습니다. 동시에 제조·포장 현장의 반복 작업과 기계 끼임·협착 등 위험 작업을 줄이기 위해서는 사람의 개입을 최소화한 공정 운영이 필요합니다.

이에 본 프로젝트는 **AI 비전 기반 불량 판독 → 불량 제거 → 정상 제품 위치·회전각 인식 → 로봇 자동 적재 → 트레이 공급·이송**의 흐름을 통합하고, 실제 설비와 시뮬레이션 환경 사이의 상태를 연계하여 공정 동작을 확인할 수 있도록 구성하였습니다.

### 1-3. 프로젝트 특장점

- **AI 비전 기반 검사와 추적:** YOLOv8로 제품 및 불량 영역을 인식하고 ByteTrack으로 제품별 ID를 추적하여 판정 안정성을 높이도록 구성
- **불량 제품 자동 제거:** 검사 결과에 따라 리젝터를 구동하고 정상 제품만 적재 공정으로 전달
- **3차원 위치·자세 인식:** Depth 카메라로 정상 제품의 X·Y·Z 위치 및 회전각을 산출하고 로봇 좌표계로 변환
- **이동 트레이 위치 추정:** 포토센서 감지 시점, 컨베이어 이송 속도 및 경과 시간으로 트레이 위치를 계산하며 후속 센서 신호로 누적 오차를 보정
- **이동 중 추적 적재:** 트레이 현재 위치와 로봇 이동 시간을 고려하여 목표 좌표를 보정하고, 이동하는 트레이에 로봇의 Y축을 동기화해 제품을 적재
- **Virtual to Real 연계:** 실제 비전·제어 데이터를 Isaac Sim과 연동해 컨베이어·로봇·리젝터 등의 공정 상태 시각화
- **통합 모니터링:** 실시간 검사 영상, 정상·불량 수량, 최근 판정 이력, 컨베이어 상태 및 디지털 트윈 화면 표시

### 1-4. 주요 기능

| 구분 | 주요 기능 | 설명 |
| --- | --- | --- |
| 제품 검사 | AI 비전 판독 | 웹캠과 YOLOv8을 이용하여 정상·불량 제품 구분 |
| 제품 추적 | ByteTrack 및 ROI | 제품별 추적 ID 관리, 검사 영역 내 판정 및 연속 프레임 기반 안정화 |
| 불량 제거 | 리젝터 구동 | 불량 판정 결과에 따라 리젝터 작동 후 복귀 |
| 위치 인식 | Depth 기반 좌표 추출 | 정상 제품의 중심 위치·깊이·회전각을 계산하여 로봇 좌표로 변환 |
| 자동 적재 | 3축 직교 로봇 | 진공 흡착 및 그리퍼 회전각 보정 기반 Pick & Place |
| 이동 트레이 추적 | 센서·속도 기반 위치 계산 | 포토센서 기준 위치 및 속도·시간으로 현재 위치 추정과 오차 보정 |
| 추적 적재 | 목표 좌표 보정 | 트레이 이동을 고려한 위치 보정 및 로봇 동기화 적재 |
| 트레이 공급 | 트레이 로더 | 적재 상태에 따라 빈 트레이 자동 공급 |
| 실물–가상 연동 | NVIDIA Isaac Sim | 장치 상태와 제어 데이터를 연계한 공정 동작 시각화 |
| 모니터링 | 통합 사용자 UI | 영상, 판정 결과, 장비 구동 상태 및 이력 확인 |

**전체 동작 시나리오**

1. 검사 컨베이어로 제품을 이송합니다.
2. 웹캠과 YOLOv8로 제품의 정상·불량 여부를 판별합니다.
3. 불량 제품은 리젝터로 제거합니다.
4. 정상 제품은 Depth 카메라를 통해 위치 좌표와 회전각을 추출합니다.
5. 3축 직교 로봇이 제품을 흡착하고, 이동 중인 트레이의 위치를 고려하여 적재합니다.
6. 설정 수량까지 적재한 후 완료 트레이를 이송하고 빈 트레이를 공급합니다.
7. 실물 공정 데이터와 Isaac Sim 및 UI를 연계해 공정 상태를 모니터링합니다.

### 1-5. 기대 효과 및 활용 분야

- **기대 효과:** 검사·선별·적재 공정의 통합 자동화, 반복·위험 작업 축소, 이동 중 적재를 통한 공정 연속성 확보, 실제 공정의 시각화와 검증 지원
- **활용 분야:** 제조·물류 자동화, 스마트 팩토리, 제품 품질 검사, 로봇 기반 Pick & Place, 디지털 트윈 공정 검증 및 교육

> **참고:** 위 내용은 제작설계서의 시스템 구성 및 설계 목표를 기술한 것으로, 별도 측정된 정확도·성능 향상률 등의 실험 결과를 의미하지 않습니다.

### 3-4. 핵심 알고리즘: 이동 트레이 추적 적재

1. **트레이 감지:** 포토센서로 트레이의 초기 기준 위치 및 감지 시간을 기록
2. **이동 위치 추정:** 컨베이어 속도와 경과 시간을 통해 트레이의 현재 위치를 지속적으로 계산
3. **오차 재보정:** 다음 센서 감지 시 실제 기준 위치에 맞춰 누적 오차를 보정
4. **적재 목표 보정:** 트레이 현재 위치, 슬롯 순서 및 로봇 이동 시간을 반영해 목표 좌표 산출
5. **동기화 적재:** 로봇 Y축을 트레이 이동 방향으로 동기화하고 지정 위치에서 제품을 내려놓음
