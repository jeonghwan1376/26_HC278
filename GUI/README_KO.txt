Isaac Sim 대형 화면 통합 GUI v10
================================

기본 배치
---------
왼쪽 70%:
- Isaac Sim 전체 공정 영상

오른쪽 30%:
- 전체 공정 카메라
- 웹캠·YOLO 화면
- 불량 검출 화면

기본 연결
---------
Isaac 영상:
- IP 172.30.1.64
- 포트 5000

메인 노트북:
- 전체 공정 영상 5100
- 웹캠·YOLO 영상 5103
- 불량 검출 영상 5104

상태 데이터:
- GUI PC가 5101 포트에서 수신

사용법
------
1. install_and_run_gui.bat 실행
2. Isaac IP와 포트 확인
3. Isaac 연결 버튼 클릭
4. 나머지 영상까지 필요하면 전체 연결 클릭

확대 기능
---------
- 영상 화면을 더블클릭하면 해당 영상만 크게 표시됩니다.
- 다시 더블클릭하거나 ESC 키를 누르면 기본 배치로 돌아옵니다.

중요
----
GUI는 Isaac 영상을 크게 표시하지만,
실제 공정 전체가 영상 프레임 안에 들어오려면
Isaac Sim 송출 PC에서 3D 카메라 시점을
전체 설비가 보이도록 맞춰야 합니다.
